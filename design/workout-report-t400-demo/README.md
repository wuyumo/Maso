# Workout report demo (t400 / t401)

Static preview only. It is not part of the app, not a production page, and it contains no real training or heart-rate records.

Open `index.html` from this folder. The page, Three.js, and the muscle mesh are local files, so a double-click works. No CDN.

The body is the app's `MuscleBody.scn`, converted to `assets/muscle-body.glb` and `assets/muscle-body.js`. See `assets/ATTRIBUTION.txt`.
